# Goal 02 milestone 1 — Engine source-analysis boundary

The Rust Engine now accepts an immutable `RepositoryAnalysis` artifact bound to exact scope, snapshot, full index-generation digest, analyzer/configuration, known elements, dependencies, verification targets and coverage gaps. Registering it requires scoped `Register` and `ManageModel` capabilities. Replacing it requires an artifact compare-and-swap; installation does not advance repository revision. Ordinary `Analyze` capability can query incomplete facts but cannot install, forge unknown elements, substitute a generation or admit incomplete analysis.

The integer reference API accepts only reference snapshots with no captured input manifest or capture metadata. Source repositories use `register_repository`; `update_model` cannot replace their bound facts. Source integer patch submission, integer revalidation and the final integer commit gate explicitly return `SourceMutationUnsupported`. Goal 01's authorization, lease, immutable-attempt, evidence, conflict and atomic-publication checks remain authoritative. Source mutation is a separate contract and is not implemented by this milestone.

The in-memory store, embedding-owned authentication/capability boundary and trusted analyzer-administrator assumptions retain Goal 01's limits. A graph digest proves content binding, not the truth or completeness of its producer's semantics.

Verification before this milestone's commit: `cargo test --locked --offline -p celetixo-engine` passed all **75** tests (the original 62 plus 13 repository-boundary tests). Tests include competing analysis-install CAS, stale snapshot/index rejection, scope/store/revocation enforcement, unknown identities, predicate membership, incomplete-admission rejection and legacy/source mutation bypass prevention. Strict package Clippy and owned-file formatting also passed. On the recorded Zig-based WSL environment, commands use `CRATE_CC_NO_DEFAULTS=1 CFLAGS='-target x86_64-linux-gnu -fPIC'`; no global compiler configuration was changed.
